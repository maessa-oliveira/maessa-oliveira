**Campo:** estação total · GNSS RTK/estático · nivelamento · drone (fotogrametria)  
**Geo:** SIRGAS 2000 · UTM · RBMC/IBGE · Civil 3D · QGIS

- Código aberto (MIT) e documentação em português.
